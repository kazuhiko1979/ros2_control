# ros2_control

ROS 2 のアプリケーションから実際のモーターを動かすために、`ros2_control` を段階的に学ぶワークスペースです。講座の実習を通して、ROS 2 からの指令がコントローラーとハードウェアインターフェースを経由して機器に届く流れを理解し、自分のロボットに応用できることを目指します。

## 前提知識

ROS 2 のパッケージ、ノード、トピック、コールバック、C++、URDF、RViz の基本操作を前提とします。

## 学習の流れ

1. `ros2_control` の基本構成を組み、各コンポーネントの役割を確認する。
2. C++ でハードウェアドライバーを設計し、ROS 2 と連携させる。
3. カスタムハードウェアインターフェースとカスタムコントローラーを実装する。
4. 実際のモーターで動作を確認し、Gazebo シミュレーターとの連携も試す。
5. 追加課題で複数のコントローラーとハードウェアインターフェースを組み合わせる。

## 学習記録と実習コード

- `docs/` にセクションごとの学習ノートを追加します。構成の役割、実行手順、期待する動作、実際の確認結果を記録します。
- `src/` に実習で作る ROS 2 パッケージを追加します。実習で使用する ROS 2 と Gazebo のバージョンは、環境を確認した段階で記録します。

## AI エージェントの連携

G-agent-platform を使う環境では、このリポジトリのルートから次のコマンドで共通基盤に連携できます。`G-agent-platform/` と `workspaces/` が同じ親ディレクトリにある構成を前提とします。

```bash
bash ../../G-agent-platform/agent-os/1-loop/link-project.sh --project "$PWD"
```

プロジェクト固有のエージェント向けルールは `AGENTS.md` に記載します。
